# 自动长截图（Auto LongShot）

自动滚动目标应用的列表界面并逐屏拼接，生成一张长图的 Android 应用。
适用于聊天记录、信息流、长文档等任何可滚动页面。

- 语言：**Kotlin**（纯 Kotlin + AndroidX，无第三方依赖）
- minSdk 26（Android 8.0+）
- **停止完全由用户手动控制**：自动滚动过程中程序绝不自行判断是否到底、绝不自动停止；
  只有用户点击 **悬浮窗「停止」按钮 / 通知栏「停止截屏」按钮 / 主界面「停止并保存」按钮** 后才结束并保存。

## 核心技术

### 1. 双截图引擎

| 路线 | 适用 | 截图方式 | 是否需要录屏授权 |
| --- | --- | --- | --- |
| **无障碍截图模式**（推荐） | Android 11+，无障碍已开启 | `AccessibilityService.takeScreenshot()` | ❌ 不需要 |
| MediaProjection 模式 | Android 8~10，或无障碍未开 | MediaProjection + ImageReader | ✅ 每次会话授权 |

同一无障碍服务同时负责两件事：注入拖动手势实现自动滚动 + 调用 `takeScreenshot` 取帧
（`accessibility_service_config.xml` 声明 `canTakeScreenshot="true"`）。
系统限流（相邻截图间隔过短返回 `INTERVAL_TIME_SHORT`）由引擎自动拉长间隔重试。

### 2. 行哈希精确重叠匹配（拼接核心）

截图是无损像素——重叠区的行在两帧之间**逐字节相等**。据此：

1. 每行计算 64 位 FNV 哈希（宽度压缩到 120 列提速，纵向保持 1:1 行对齐）；
2. 行内灰度偏差 ≤8 的"空白行"不参与打分（它们在任何偏移下都"相等"，是假峰根源）；
3. 全范围扫描候选重叠，统计**内容行精确命中数**：
   真峰数百行命中、假峰 ≈ 0，分离度为数量级（实测命中 316/320 行）。

> 踩坑记录：早期使用"采样相似度"（色差阈值内算匹配），在空白多、气泡等距排布的
> 界面上假峰无法根除，只能靠补丁压制。改为精确匹配后问题从算法层面消失。
> 参考：[zengfw/LongScreenShot](https://github.com/zengfw/LongScreenShot)、
> [ericleong/scrollshot](https://github.com/ericleong/scrollshot)。

配套鲁棒性措施：

- **固定 UI 区自动检测与裁除**：聊天页标题栏、输入栏每帧像素级相同，通过逐行像素
  比对自动找出上下边缘的静态块并裁除（不硬编码任何应用尺寸）；
- **滚动条列屏蔽**：行哈希排除最右侧 3% 列，滚动条移动不污染真峰；
- **双帧一致性稳定检测**：连续两帧指纹一致才认为画面静止，绝不拼接运动中的帧。

### 3. 工程细节

- 拖动结束速度压低（单段慢速手势），减小抬起惯性对滑动距离的扰动；
  ⚠️ 多段手势注入在部分 ROM（实测某 MIUI Android 17 预览版）会触发 system_server
  重启，切勿改回；
- 画布行画像**增量缓存**：长图每帧只对新拼入部分补算哈希，成本 O(新增高度) 而非 O(总高)；
- **动态内存预算（按字节，非像素）**：预算随设备当前可用内存伸缩（96~320MB），
  每次拼接前校验瞬态峰值（成品图×2 + 新帧三者同时驻留），超预算自动停止并保存；
  另有系统可用内存看门狗（<400MB 主动收尾）与累计高度硬上限兜底；
- 用户设定的**最大屏数**实时生效，达到后自动停止并保存（也可随时手动停止）。

## 构建

已验证环境：AGP 8.13.1 + Gradle 8.13 + JDK 17 + SDK Platform 37 + build-tools 36.0.0。

```bash
./gradlew :app:assembleDebug
# 产物：app/build/outputs/apk/debug/app-debug.apk
```

若本机 SDK 平台目录名为 `android-37.0`（部分渠道安装的 SDK），需复制一份为 `android-37`
并修正 `source.properties`（`AndroidVersion.ApiLevel=37.0` → `37`）与 `package.xml` 中的路径。

## 使用步骤

1. 打开目标应用，进入要截取的页面，**停留在最上方**。
2. 回到本 App，确认状态（无障碍 / 悬浮窗 / 通知）均已开启，点击**开始截屏**：
   - Android 11+ 且无障碍已开启：直接进入无障碍截图模式，自动开始滚动；
   - Android 8~10 或无障碍未开启：走 MediaProjection 路线，每次会话授权一次录屏。
3. 截屏开始后自动向上滚动并逐屏拼接（悬浮窗显示已截屏数，通知栏常驻进度）。
4. 到达想要的范围后，点**任意一个停止入口**（悬浮窗 / 通知栏 / 主界面「停止并保存」）。
5. 长图自动保存到相册 `Pictures/LongScreenshots/自动长截图_yyyyMMdd_HHmmss.png`。

## 设置项

| 设置 | 默认 | 说明 |
| --- | --- | --- |
| 滑动距离 | 60% | 每次拖动滚动的距离。越大越快但重叠越少；越小越稳越慢（10~85） |
| 截图间隔 | 900ms | 滚动完成到截图之间的基础等待（下限 800，界面图片多可调大） |
| 输出缩放 | 1.0 | 长图输出宽度 = 屏宽 × 缩放；超长图建议 0.75/0.5 降内存 |
| 最大屏数 | 200 | 达到该屏数自动停止并保存（0 改动即时生效） |

## 已知限制

- 目标应用的抬起惯性会让实际滑动距离波动（可达 ±300px），行哈希匹配已兼容，
  但极快的界面动画仍可能引入接缝；
- 到达列表底部后拖动会被回弹拒绝，属正常现象；
- 含防截屏标志（FLAG_SECURE）的界面无法截取（系统限制）。
